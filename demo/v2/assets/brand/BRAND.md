# ProtocolPulse identity

Emerald `#148252`, forest `#12392B`, sage `#AED4B9`, white `#F5FAF6`.

The mark combines a protocol page/P monogram with a raised pulse route. The motion version uses actual extruded geometry, a white ceramic ribbon, paper satellites and soft studio shadows. Slow rotation and orbit communicate continuity. No blue/purple palette remains in the selected video.

Display: Bahnschrift. Supporting type: Segoe UI. Use generous white space, forest text, restrained emerald emphasis and smooth motion. Reserve alerts and uncertainty colours for the actual product UI.

`symbol.svg` and `lockup.svg` are editable vectors; `symbol.png` is transparent. `identity.png` is a reference sheet. `scene.html` and `frames3d/` define the actual moving 3D artwork. Superseded preview files are production history; `intro-3d.png`, `outro-3d.png` and the final film represent the selected direction.
